# Обнуление — лендинг гостевого посещения (12 июля, 8:30 по Киеву)

Одноэкранная страница регистрации гостей на программу «Обнуление». Форма
собирает имя, фамилию, телефон и Telegram, после отправки показывает ссылку
на @Otdel_Zaboti_Individual для добавления в Telegram-канал, и дублирует
каждую заявку в Google Документ.

## Файлы

- `index.html` — сама страница (готова к использованию как есть, ничего собирать не нужно).
- `google-apps-script/Code.gs` — скрипт, который принимает заявки и дописывает их в Google Документ.

## Установка (5 минут)

1. **Google Документ**
   - Создайте пустой Google Документ.
   - Скопируйте его ID из адресной строки: `docs.google.com/document/d/ЭТОТ_ID/edit`.
   - Откройте документ → `Расширения` → `Apps Script`.
   - Вставьте туда содержимое `google-apps-script/Code.gs`, впишите ID в переменную `DOC_ID`.
   - `Деплой` → `Новый деплой` → тип `Веб-приложение`. Execute as: **Me**, Who has access: **Anyone**.
   - Скопируйте выданный URL веб-приложения.

2. **index.html**
   - Откройте `index.html`, найдите строку `GOOGLE_SCRIPT_URL` и вставьте туда скопированный URL.

3. **Публикация на WordPress**
   - Вариант А (проще всего): страница → блок **Custom HTML** → вставить содержимое `index.html` целиком (без `<html>/<head>/<body>`, либо весь файл — блок Custom HTML это переживёт) и сделать её страницей без темы/шапки сайта (шаблон "Blank"/"Canvas", если используется Elementor/Divi/Astra и т.п.).
   - Вариант Б: загрузить `index.html` на хостинг как отдельный статический файл и дать на него прямую ссылку (например, `/obnulenie/index.html`) — многие рекламные лендинги делают именно так, чтобы не зависеть от темы WordPress.
   - Если используется конструктор (Elementor/Bricks/Divi) — добавьте виджет **HTML** на пустую страницу и вставьте туда содержимое файла.

4. **Ссылка на Telegram-канал**
   - В коде уже стоит `@Otdel_Zaboti_Individual`. Если ник поменяется — заменить в двух местах в `index.html` (`href="https://t.me/..."` и текст подсказки).

## Проверка

Откройте страницу, заполните форму тестовыми данными и отправьте — новая строка должна появиться в Google Документе в течение нескольких секунд.
