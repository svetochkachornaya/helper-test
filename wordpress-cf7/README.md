# Интеграция формы CF7 «Обнуление. Гостевой визит»

## Самый простой способ — один файл

1. Шаги 1 и 2 (поля формы и текст письма) — как раньше, через
   `Контакты` → `Контактные формы` → «Обнуление. Гостевой визит»:
   - Вкладка **Форма** → вставить содержимое `cf7-form-tab.txt`.
   - Вкладка **Почта** → вставить содержимое `mail-tab-template.txt`.
   - Нажать **Сохранить** после каждой вкладки.

2. Открой страницу с формой (на сайте, в редакторе).
3. Удали с неё все старые блоки, которые относятся к этой секции
   (старый шорткод формы, если он был отдельным блоком, старое
   оформление и т.п.) — если не уверена что удалять, просто добавь новый
   блок ниже, ничего не удаляя.
4. Добавь блок **"Произвольный HTML" / "Custom HTML"** (значок "+"
   → в поиске написать `HTML`).
5. Открой файл `full-page.html`, скопируй **весь текст целиком**
   (это и дизайн, и форма, и экран "Заявка принята", и отправка в Google
   Таблицу — всё в одном месте).
6. Вставь этот текст в блок Custom HTML.
7. Сохрани / обнови страницу.
8. Открой страницу на **реальном сайте** (не в редакторе) и проверь: должна появиться премиальная страница с формой из четырёх полей, полями Имя/Фамилия/Телефон/Telegram, и кнопкой «Записаться на 12 июля».

Больше никаких CSS, отдельных блоков и вкладок искать не нужно — всё в
этом одном файле.

## Если форма не появилась, а виден текст в квадратных скобках

Если после сохранения на странице видно буквально
`[contact-form-7 id="6673d89" ...]` вместо самой формы — значит, на этом
сайте нужно вставить шорткод отдельным блоком. Тогда:

1. В коде `full-page.html` найди строку `[contact-form-7 id="6673d89" title="Обнуление. Гостевой визит"]`.
2. Удали её из блока Custom HTML.
3. На странице сразу после блока Custom HTML (в том месте, где должна
   быть форма) добавь отдельный блок **"Шорткод" / "Shortcode"** и
   вставь туда именно эту строку.
4. Сохрани страницу — так форма должна отрисоваться корректно, а
   оформление и скрипт продолжат работать, потому что блоки просто идут
   один за другим на одной странице.

## Проверка

Заполни форму на **опубликованной** странице (не в редакторе) тестовыми
данными и отправь — должен появиться экран "Заявка принята!" со ссылкой
на @Otdel_Zaboti_Individual, а в Google Таблице — новая строка с данными.

## Файлы в этой папке

- `full-page.html` — **используй этот**, всё в одном месте.
- `cf7-form-tab.txt` — текст для вкладки "Форма" в CF7.
- `mail-tab-template.txt` — текст для вкладки "Почта" в CF7.
- `style.css`, `success-and-sync.html` — старый вариант с раздельными
  блоками CSS/HTML, оставлен на случай, если понадобится более гибкая
  настройка. Для обычной установки не нужен — используй `full-page.html`.
