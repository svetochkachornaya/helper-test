# Интеграция формы CF7 «Обнуление. Гостевой визит»

Форма `[contact-form-7 id="6673d89" title="Обнуление. Гостевой визит"]` уже
есть на сайте. Ниже — как настроить именно её: поля, премиальное
оформление, экран "Заявка принята" со ссылкой на Telegram и дублирование
заявок в ту же Google Таблицу (через уже настроенный Apps Script — его
менять не нужно).

## 1. Поля формы

`Контакты` (Contact) → `Контактные формы` (Contact Forms) → открой форму
«Обнуление. Гостевой визит» → вкладка **Форма** (Form).

Замени содержимое на файл `cf7-form-tab.txt` из этой папки (скопируй и
вставь целиком). Это добавит поля: Имя, Фамилия, Телефон, Telegram.

Нажми **Сохранить**.

## 2. Письмо на почту (необязательно, но рекомендуется)

Если хочешь получать заявки ещё и на email — открой вкладку **Почта**
(Mail) и вставь туда шаблон из `mail-tab-template.txt`. Это нужно, потому
что названия полей поменялись (`your-name`, `your-lastname` и т.д.) —
старый шаблон писем мог ссылаться на другие названия и присылать пустые
письма.

## 3. Премиальное оформление

`Внешний вид` (Appearance) → `Настроить` (Customize) → `Дополнительные
CSS` (Additional CSS). Вставь туда целиком содержимое файла `style.css`
из этой папки. Сохрани и опубликуй.

## 4. Экран "Заявка принята" + отправка в Google Таблицу

На странице с формой, **сразу после блока с шорткодом** CF7, добавь ещё
один блок **"Произвольный HTML" / "Custom HTML"** и вставь туда целиком
содержимое файла `success-and-sync.html` из этой папки.

## 5. Оборачиваем форму в карточку (визуально)

Чтобы сама форма выглядела как карточка (со скруглёнными углами и рамкой,
как в дизайне лендинга) — на странице:

1. Добавь блок **"Группа" / "Group"**.
2. В настройках блока справа (вкладка **Дополнительно / Advanced**) в поле
   **Дополнительный класс CSS / Additional CSS class(es)** впиши:
   `obnulenie-card`
3. Внутрь этой группы добавь:
   - блок **Заголовок** с текстом `Записаться гостем`
   - блок **Абзац** с текстом `Заполни данные — подтверждение придёт мгновенно`
   - блок **Шорткод** с содержимым `[contact-form-7 id="6673d89" title="Обнуление. Гостевой визит"]`
   - (опционально) блок **Абзац** с классом `obnulenie-fineprint` и текстом
     про согласие на обработку данных

Порядок блоков на странице в итоге:
1. Твой блок с левой частью (хедлайн "ОБНУЛЕНИЕ", дата/время, буллиты) —
   можно оставить как есть или взять из `index.html` в корне репозитория.
2. Группа `obnulenie-card` с формой CF7 (шаги выше).
3. Custom HTML с `success-and-sync.html`.

## Проверка

Заполни форму на живой странице сайта (не в редакторе, а на опубликованной
версии) — после отправки форма должна скрыться, появиться блок "Заявка
принята!" со ссылкой на @Otdel_Zaboti_Individual, а в Google Таблице —
новая строка с данными.
